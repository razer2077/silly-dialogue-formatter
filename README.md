# Russian Dialogue Formatter

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern), которое автоматически конвертирует русские диалоги из формата с тире (`— реплика, — сказала она. — продолжение`) в формат с кавычками и звёздочками (`"реплика," *сказала она.* "продолжение"`).

## Зачем

DeepSeek и подобные модели часто выдают диалоги в формате с длинными тире, что плохо смотрится в ролёвке. Это расширение делает форматирование автоматически. Deepseek такой лоботомит, что ему плевать на форматирование и у меня просто сгорела жопа и я изобрел с помощью божественного клодика такую тему и теперь навсегда на любой модели можно забыть про правила форматирования. Да бывают косяки, но они очень редкие прямо совсем редкие.

## Что умеет

- Превращает речь в `"..."`, ремарки/действия — в `*...*`.
- Понимает ~440 глаголов речи/действия/мимики и ~250 слов-маркеров.
- Корректно обрабатывает вставки-перебивки (`— слышишь? —`) внутри речи.
- Различает атрибуцию через двоеточие (`Sery вздохнула: — речь`).
- Обрабатывает стилистические тире (`берёшь — берёшь по-умному`).
- Поддерживает разные виды тире: `—` `–` `-`.
- Не трогает чистое повествование без диалогов.
- Не трогает уже отформатированные сообщения.
- Сохраняет внутренние «ёлочки» цитат-эхо (`— Он мне говорит: «Иди отсюда»`).

## Покрытие тестами

**113 тест-кейсов** прогнаны через node:
- 13 реальных абзацев из ролёвки на DeepSeek
- 20 edge-cases (имена, дефисы, латиница, многоточия, стилистические повторы)
- 50 экзотических кейсов (эмодзи, цифры, спецсимволы, сложная пунктуация, многоязычные реплики)
- 30 ultra-rare кейсов (эмоции, природа, оружие, RP-ситуации, романтические сцены)

## Установка

1. Найди папку SillyTavern на своём компьютере, в ней путь:
   ```
   public/scripts/extensions/third-party/
   ```
2. Скопируй в эту папку весь репозиторий целиком (или клонируй):
   ```
   git clone https://github.com/razer2077/silly-dialogue-formatter.git
   ```
   Должна получиться папка `third-party/silly-dialogue-formatter/` с файлами `manifest.json`, `index.js`, `README.md`.
3. Перезапусти SillyTavern.
4. Открой меню **Extensions** (иконка кубиков), найди **Russian Dialogue Formatter** и убедись что включено.
5. **Отключи (или удали) все свои regex-правила** для диалогов — они больше не нужны.
6. Запроси новый ответ у бота — он сразу придёт отформатированным.

## Обновление

```bash
cd /путь/к/silly-dialogue-formatter
git pull
```

Перезапусти SillyTavern. В консоли (F12 → Console) должна быть строка `[Russian Dialogue Formatter] loaded, version X.Y.Z`.

## Как работает

Алгоритм:

1. Если абзац уже отформатирован (начинается с `"` или `*`) — не трогаем.
2. Если абзац — чистое повествование без тире-диалогов — не трогаем.
3. Защищаем короткие вставки-перебивки (`— слышишь? —`) от ложного разреза.
4. Делим абзац на сегменты по разделителю `<знак> — <текст>`.
5. Классифицируем каждый сегмент:
   - Содержит глагол речи / действия → **ремарка** (`*...*`).
   - Содержит часть тела или типаж в начале → **ремарка**.
   - Содержит местоимение `он/она/они/оно` → **ремарка**.
   - Иначе → **речь** (`"..."`).
6. Принудительное чередование: после речи → ремарка, после ремарки → речь.
7. Постобработка: чистка висячих тире, потерянных звёздочек, склейка коротких односложников.

## Расширение списков

Если попадается глагол которого нет в списке — открой `index.js`, найди массив `ACTION_STEMS` и добавь основу слова (без окончания):

```js
const ACTION_STEMS = [
  // ...
  'фыркн','выдох','вздох',
  'мой_новый_глагол',  // ← добавь сюда
  // ...
];
```

Сохрани файл, перезапусти SillyTavern.

## Известные ограничения

Эти **очень редкие** случаи могут обрабатываться неидеально (~1% реальных абзацев):

1. **Реплика начинается с italic-мысли**: `— *Боже,* — выдохнула она.` — звёздочка в начале сейчас расценивается как «уже отформатировано», и абзац не трогается.

2. **Звёздочки внутри реплики**: `— Не подходи! *она отступила* — Я не шучу!` — звёздочки внутри речи путают сплиттер.

3. **Двойные вложенные ремарки в звёздочках**: `*"Опять он",* — мелькнуло в голове.` — может остаться лишняя звёздочка.

Если попадётся проблемный абзац — открой issue или скинь его в чат, и алгоритм будет улучшен.

# Russian Dialogue Formatter

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern), которое автоматически конвертирует русские диалоги из формата с тире (`— реплика, — сказала она. — продолжение`) в формат с кавычками и звёздочками (`"реплика," *сказала она.* "продолжение"`).

## Зачем

DeepSeek и подобные модели часто выдают диалоги в формате с длинными тире, что плохо смотрится в ролёвке. Это расширение делает форматирование автоматически, заменяя громоздкую цепочку из 20+ regex-правил одним алгоритмическим решением.

## Что умеет

- Превращает речь в `"..."`, ремарки/действия — в `*...*`.
- Понимает глаголы речи, действия, мимики (~400 основ).
- Различает части тела, типажи (~250 слов-маркеров).
- Корректно обрабатывает вставки-перебивки (`— слышишь? —`) внутри речи.
- Обрабатывает стилистические тире (`берёшь — берёшь по-умному`).
- Не трогает чистое повествование без диалогов.
- Не трогает уже отформатированные сообщения.

## Установка

1. Найди папку SillyTavern на своём компьютере, в ней путь:
   ```
   public/scripts/extensions/third-party/
   ```
2. Скопируй в эту папку весь репозиторий целиком (или клонируй):
   ```
   git clone https://github.com/razer2077/silly-dialogue-formatter.git
   ```
   Должна получиться папка `third-party/silly-dialogue-formatter/` с файлами `manifest.json`, `index.js`, `README.md`.
3. Перезапусти SillyTavern.
4. Открой меню **Extensions** (иконка кубиков), найди **Russian Dialogue Formatter** и убедись что включено.
5. **Отключи (или удали) все свои regex-правила** для диалогов — они больше не нужны.

## Как работает

Алгоритм:

1. Если абзац уже отформатирован (начинается с `"` или `*`) — не трогаем.
2. Если абзац — чистое повествование без тире-диалогов — не трогаем.
3. Защищаем короткие вставки-перебивки (`— слышишь? —`) от ложного разреза.
4. Делим абзац на сегменты по разделителю `<знак> — <текст>`.
5. Классифицируем каждый сегмент:
   - Содержит глагол речи / действия → **ремарка** (`*...*`).
   - Содержит часть тела или типаж в начале → **ремарка**.
   - Содержит местоимение `он/она/они/оно` → **ремарка**.
   - Иначе → **речь** (`"..."`).
6. Принудительное чередование: после речи → ремарка, после ремарки → речь (с приоритетом сильных сигналов).
7. Постобработка: чистка висячих тире, потерянных звёздочек.

## Расширение списков

Если попадается глагол которого нет в списке (например модель использует редкое слово) — открой `index.js`, найди массив `ACTION_STEMS` и добавь основу слова (без окончания):

```js
const ACTION_STEMS = [
  // ...
  'фыркн','выдох','вздох',
  'мой_новый_глагол',  // ← добавь сюда
  // ...
];
```

Сохрани файл, перезапусти SillyTavern.

## Известные ограничения

- Очень сложные многоуровневые диалоги (2+ вставки-перебивки внутри речи) могут обрабатываться неидеально.
- Если модель сама путает речь и действие в исходнике (выдаёт `— она кивнула —`), классификатор может ошибиться.
- Эвристика по русскому языку не на 100% — иногда возможны ложные срабатывания.
